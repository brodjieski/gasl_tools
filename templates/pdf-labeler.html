🏷️ About PDF Labeler

The PDF Labeler tool helps you create multiple labeled copies of a PDF document. Upload a PDF file and provide a list of labels, and the tool will generate a concatenated PDF file containing one copy of the original document for each label, with the label prominently displayed at the top of the first page.

This is particularly useful for creating role-specific copies of documents like heat sheets, where each copy needs to be labeled for different positions (e.g., "Announcer", "Lane Organizer", "Clerk of Course", etc.).
